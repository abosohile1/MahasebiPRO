# محاسبي PRO V6 — حزمة البناء للهاتف

هذه الحزمة مخصصة لبناء APK على الهاتف نفسه.

**ابدأ من المجلد `android/` داخل AndroidIDE.**

المشروع يحتوي على:
- تطبيق Android للخادم الرئيسي.
- واجهة البرنامج داخل `assets/www`.
- ServerService يعمل كـ Foreground Service.
- قاعدة SQLite على الهاتف الرئيسي.
- مشروع العميل في `client/`.
- الخادم المرجعي في `server/`.

راجع `build-on-phone.md` للخطوات الكاملة.
